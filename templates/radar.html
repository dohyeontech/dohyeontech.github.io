HOW IT READS

숫자를 읽는 방법

김프 = 업비트 원화가 ÷ (바이낸스 USDT가 × USD/KRW) − 1

같은 코인이 국내에서 얼마나 더 비싸게 거래되는지를 봅니다. 값이 +면 국내가 비싼 상태, −면 국내가 싼 상태(역프리미엄)입니다. 업비트는 실시간 스트림의 마지막 체결가, 바이낸스는 현물 ticker/price의 마지막 가격을 씁니다.

업-빗 괴리 = 업비트 원화가 ÷ 빗썸 원화가 − 1

같은 시각 두 국내 거래소의 원화 체결가 차이입니다. +면 업비트가 더 비싸고, −면 빗썸이 더 비쌉니다. 빗썸에 같은 티커가 없거나 거래가 멈춘 종목은 --로 둡니다. 두 값이 크게 벌어져도 전송 지연·입출금 정지·수수료 때문에 실제 차익이 되지는 않습니다.

테더 김프는 환율 오차를 알려 줍니다

기준 환율은 하루 한 번 고시되는 공개 환율이라 은행 실시간 고시와 차이가 납니다. 업비트의 USDT 시세는 국내 참가자가 실제로 원화를 바꾸는 값이므로, 두 값의 차이를 테더 김프로 함께 보여 줍니다. 김프를 읽을 때 이만큼은 환율 기준 차이일 수 있다는 뜻입니다.

⚡ 급변 포착은 이 화면을 보는 동안의 변화

세 가지를 자동으로 표시합니다. 24시간 등락률이 ±5%를 넘으면 🔥 급등·❄️ 급락, 페이지를 열어 둔 사이 약 1분 동안 가격이 1.2% 이상 움직이면 분당 변동률 배지, 같은 시간에 김프가 0.8%p 이상 벌어지면 ⚡ 김프급변입니다. 단기 배지는 업비트 스트림 틱이 쌓인 뒤부터 나오므로 화면을 열자마자 비어 있는 것이 정상입니다.

SOURCES & LIMITS

데이터 출처와 한계

  • 업비트 wss://api.upbit.com/websocket/v1 — ticker 스트림으로 KRW 마켓 현재가·24시간 거래대금·등락률을 실시간 수신. 마켓 코드 목록만 api.upbit.com/v1/market/all에서 10분에 한 번 받습니다.
  • 업비트 REST를 폴링하지 않는 이유 /v1/ticker는 Origin이 붙은 브라우저 요청을 초당 1회 수준으로 조이고, 초과분에는 429를 돌려주는데 그 응답에는 Access-Control-Allow-Origin이 없습니다. 300종을 3번에 나눠 15초마다 부르는 방식은 그대로 CORS 오류가 됩니다. 그래서 시세는 스트림으로 받고, 스트림이 막히는 네트워크에서는 청크를 10초씩 띄운 REST 보조 수집(약 60초 주기)으로 내려갑니다.
  • 빗썸 api.bithumb.com/public/ticker/ALL_KRW — KRW 마켓 전체의 현재가·24시간 거래대금·등락률을 한 번에 받아 20초마다 갱신합니다. 이 주소는 Access-Control-Allow-Origin: *를 돌려주므로 브라우저에서 직접 호출되며, 중계 프록시를 두지 않습니다. 응답이 실패하면 api.bithumb.com/v1/ticker로 주요 종목만 받아 이어 갑니다.
  • 바이낸스 api.binance.com/api/v3/ticker/price — 현물 USDT 가격(15초). fapi.binance.com/fapi/v1/premiumIndex — 선물 마크가격, 현재 펀딩비, 다음 정산 시각. 앞 주소가 지역 제한(HTTP 451)으로 막히면 data-api.binance.vision 미러, 펀딩은 Gate.io 공개 API로 대체하고 배지에 출처를 표시합니다.
  • 환율 공개 환율 API 4곳을 동시에 불러 가장 최근 고시 날짜의 값을 씁니다(currency-api.pages.dev · open.er-api.com · fawazahmed0 jsDelivr · frankfurter). 하루 늦은 고시값을 쓰면 김프 전체가 그만큼 밀리기 때문입니다. 어느 출처의 며칠치인지 카드에 적고 5분 캐시합니다.
  • 비교 대상은 업비트 KRW 마켓 중 바이낸스에 같은 티커의 USDT 현물 페어가 있는 종목입니다. 업비트에만 상장된 코인은 김프를 계산할 수 없어 표에서 빠지고, 상단에 비교 가능 종목 수를 적습니다. 빗썸 괴리는 그중 빗썸에 같은 티커가 있는 종목에만 붙습니다.
  • 호가 차이 업비트·빗썸·바이낸스의 마지막 체결 시각은 몇 초 어긋날 수 있고, 저유동성 종목은 호가 한 단위가 김프나 괴리율을 몇 % 움직입니다.
공개 API 시세 기준 정보 제공용이며 투자 조언이 아닙니다. 이 화면은 매수·매도 신호를 제공하지 않습니다. 김프·거래소 간 괴리·펀딩비는 차익거래 기회로 보이더라도 전송 지연·입출금 정지·수수료·세금·환전 비용으로 손실이 날 수 있습니다. 표시 값은 거래소와 환율 API의 응답을 그대로 계산한 것으로, 표시 오류나 지연이 있을 수 있습니다.
