WHY CLIENT-SIDE

왜 서버를 거치지 않게 만들었나

이 도구들에 붙여넣는 값은 대개 사고 현장에서 나온 것입니다. 내부 사설 IP, 사내 도메인, 침해 계정의 메일 주소, 아직 폐기하지 못한 세션 토큰이 섞여 있습니다. 그런 문자열을 무료 변환 사이트에 넣는 순간, 입력값은 남의 서버 로그에 남고 그 로그가 다시 유출될 수 있습니다. 편하려고 연 도구가 2차 유출 경로가 되는 셈입니다.

그래서 이 세 도구는 서버가 아예 없습니다. 페이지를 열 때 받는 것은 정적 HTML·CSS·JS뿐이고, 입력값은 탭의 메모리에서만 처리됩니다. 쿠키도, 로컬스토리지도, 분석 스크립트도 쓰지 않습니다. 새로고침하면 입력값은 사라집니다.

브라우저 개발자 도구의 Network 탭을 열어 두고 써 보시면 입력할 때 요청이 하나도 나가지 않는 것을 직접 확인할 수 있습니다.

NO UPLOAD
입력값을 읽고 쓰는 코드는 전부 이 페이지에 실려 내려온 자바스크립트입니다. 전송 API를 호출하지 않습니다.
NO PERSISTENCE
쿠키·로컬스토리지·인덱스드DB를 쓰지 않습니다. 탭을 닫으면 남는 값이 없습니다.
NO TRACKING
광고·분석 스크립트를 넣지 않았습니다. 외부에서 받는 것은 폰트뿐입니다.
USAGE NOTES

쓸 때 알아 둘 것

  • 디팡은 표기만 바꿉니다. 실제 접속을 막는 조치가 아니라, 보고서·티켓·메신저에서 링크가 그대로 눌리지 않게 하는 표기 규칙입니다. 메일 본문에 넣을 때는 링크가 자동으로 활성화되지 않는지 한 번 더 확인하세요.
  • JWT 검사기는 서명을 검증하지 않습니다. 디코딩은 누구나 할 수 있는 일이라, 여기서 “유효하다”는 것은 형식과 시각이 맞는다는 뜻입니다. 서명 검증은 서버의 키로 따로 해야 합니다.
  • CVSS는 Base 점수만 계산합니다. Temporal(악용 코드 성숙도 등)과 Environmental(자산 중요도)은 환경마다 달라서 넣지 않았습니다. 실제 위험도 판단에는 그 두 축을 함께 보세요.
  • 결과는 참고용입니다. 자동 추출은 정규식이라 파일 확장자처럼 보이는 조각을 도메인으로 잡을 수 있습니다. 중요한 판단 전에는 원문과 대조하세요.
