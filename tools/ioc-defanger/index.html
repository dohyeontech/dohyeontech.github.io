IOC 추출 · 디팡 도구

침해 로그, 메일 원문, 분석 리포트를 그대로 붙여넣으면 IPv4·도메인·URL·MD5·SHA1·SHA256·CVE·이메일을 뽑아 종류별로 묶고 중복을 합칩니다. 결과는 디팡·리팡 두 가지 표기로 바꿔 복사할 수 있습니다. 모든 처리는 이 페이지 안에서만 실행되고 입력값은 전송되지 않습니다.

IN-PAGE REGEX ONLY NO UPLOAD DEDUP + COUNT
INPUT / 원문 붙여넣기

붙여넣은 내용은 브라우저 메모리에서만 처리되며 어디에도 저장되지 않습니다.

RESULT / 0 UNIQUE

표기는 원본과 디팡을 섞어 넣어도 인식합니다. 파일 확장자처럼 보이는 조각(config.json 등)은 도메인에서 제외합니다.

DEFANG RULES

이 도구가 바꾸는 규칙

  • https://example.com/a → hxxps://example[.]com/a (프로토콜 머리와 점을 무력화)
  • 185.220.101.47 → 185[.]220[.]101[.]47
  • ops@corp-example.co.kr → ops[@]corp-example[.]co[.]kr
  • 리팡은 hxxp(s), [.] (.) {.}, [@] (@) [at]를 원래 문자로 되돌립니다.

MD5·SHA 해시와 CVE 번호는 링크로 동작하지 않으므로 변형하지 않습니다. 티켓이나 위키에 붙일 때는 디팡 표기를, 다시 검색할 때는 리팡 표기를 쓰면 됩니다.
