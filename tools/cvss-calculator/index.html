CVSS v3.1 Base Score 계산기

기본 메트릭 8개를 눌러 점수를 계산합니다. CVSS:3.1/AV:N/AC:L/… 형태의 벡터 문자열을 붙여넣으면 그 값으로 메트릭이 자동으로 맞춰집니다. FIRST.org 명세의 수식과 반올림 규칙을 그대로 옮겼고, 공개된 계산 예제 28건과 대조해 검증했습니다.

HOW IT IS COMPUTED

점수가 나오는 과정

CVSS v3.1의 기본 점수는 Exploitability와 Impact를 더한 뒤, Scope가 바뀐 경우 1.08을 곱하고 10을 넘지 않게 자른 다음 소수 첫째 자리로 올림합니다.

  • ISS = 1 - (1-C)(1-I)(1-A)
  • Impact = 6.42 × ISS (Scope Unchanged) / 7.52 × (ISS-0.029) - 3.25 × (ISS-0.02)^15 (Scope Changed)
  • Exploitability = 8.22 × AV × AC × PR × UI — PR 가중치는 Scope가 바뀌면 달라집니다(0.68 / 0.5).
  • Base = Roundup(min(Impact + Exploitability, 10)) 또는 Scope Changed에서 Roundup(min(1.08 × (Impact + Exploitability), 10))

Roundup은 명세 부록 A의 권고대로 입력에 100,000을 곱해 정수로 만든 뒤 정수 연산으로 올림합니다. 부동소수점 오차 때문에 4.02가 4.1로, 4.00이 4.0으로 정확히 떨어지는지가 이 부분에서 갈립니다.

심각도 구간은 0.0 None, 0.1–3.9 Low, 4.0–6.9 Medium, 7.0–8.9 High, 9.0–10.0 Critical입니다.

SCOPE & LIMITS

이 계산기가 다루지 않는 것

  • Temporal(악용 코드 성숙도 E, 패치 수준 RL, 보고 신뢰도 RC)과 Environmental(CR·IR·AR, 수정 메트릭)은 계산하지 않습니다. 두 축은 조직과 시점에 따라 달라서, 필요하면 명세의 7.2·7.3절 수식을 같은 방식으로 적용해야 합니다.
  • CVSS v4.0은 메트릭 구성과 점수 체계가 완전히 달라 이 계산기로 계산되지 않습니다. 벡터가 CVSS:4.0/으로 시작하면 값을 받지 않습니다.
  • 점수는 취약점의 기술적 특성만 반영합니다. 실제 대응 우선순위는 자산 노출도, CISA KEV 등재 여부, 실제 악용 정황과 함께 판단하세요.
